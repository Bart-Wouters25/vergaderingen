# Comtomeet — Jouw Persoonlijke Activiteitencentrale

Een mobiel-eerste webapplicatie voor het organiseren en beheren van
vergaderingen en activiteiten. Comtomeet biedt een overzichtelijke,
app-achtige ervaring rechtstreeks in de browser.

## Wat doet deze app?

- Vergaderingen en activiteiten plannen en beheren
- Overzichtelijke, app-achtige interface (geïnspireerd op mobiele apps)
- Werkt als Progressive Web App (PWA) — installeerbaar op smartphone of
  desktop, met een eigen icoon en app-achtige ervaring

## Technologie

- HTML / CSS / JavaScript — één overzichtelijk bestand (`vergadering-app.html`)
- **PWA-ondersteuning** via `manifest.json`, met een eigen app-icoon
  (`icoon.svg`) en themakleur
- Mobiel-eerste ontwerp
